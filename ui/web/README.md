# OurCord Web UI (Phase-2 placeholder)

Phase-1 has no web client — only the daemon + `ourcord-cli` and the control/service Workers are shipped. A browser-based client (likely React, reusing the same control HTTP API as the desktop UI) is phase-2 work; see plan.md `ph2-u1-ui-framework` for the framework decision and `ph2-u2-ui-auth-lobby` / `ph2-u3-ui-voice-room` for scope.
