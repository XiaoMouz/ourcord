# OurCord Desktop UI (Phase-2 placeholder)

Phase-1 ships the daemon and Workers (control + service) only; there is no first-party desktop UI yet — `ourcord-cli` is the supported client. The desktop UI (planned: Tauri + React, talking to the local daemon over its loopback HTTP API) is phase-2 work. See plan.md `ph2-u1-ui-framework`, `ph2-u2-ui-auth-lobby`, and `ph2-u3-ui-voice-room`.
